## 📦 新增功能

### 1. 订单管理系统

#### 1.1 订单状态管理
实现了完整的订单生命周期管理，支持5个订单状态：
- **PENDING** (客户下单) - 订单初始状态
- **CONFIRMED** (商家确认) - 商家确认订单
- **PREPARING** (备货完成) - 商家备货完成
- **SHIPPING** (开始发货) - 订单已发货
- **COMPLETED** (交易完成) - 交易成功完成
- **CANCELLED** (已取消) - 订单已取消

#### 1.2 订单取消机制
- **客户取消权限**：只能在开始发货前（SHIPPING状态前）取消订单
- **商家取消权限**：可以在交易完成前（COMPLETED状态前）取消订单
- **取消原因记录**：记录取消人角色（CUSTOMER/SELLER）和取消原因
- **库存自动恢复**：订单取消时自动恢复商品库存

#### 1.3 库存管理
- 下单时自动扣减库存
- 取消订单时自动恢复库存
- 库存不足时拒绝下单

### 2. 收藏功能

- 客户可收藏商品
- 客户可取消收藏
- 查看收藏列表（按收藏时间倒序）
- 检查商品是否已收藏
- 客户-商品唯一约束（避免重复收藏）

### 3. 购物车功能

- 添加商品到购物车（支持数量）
- 更新购物车商品数量
- 从购物车移除商品
- 查看购物车列表
- **购物车批量下单**：从购物车选择多件商品创建订单
- **购物车转收藏**：批量将购物车商品转为收藏
- 清空购物车

## 🗄️ 数据库变更

### 新增表

#### 1. orders（订单表）
```sql
CREATE TABLE orders (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    order_number VARCHAR(50) NOT NULL UNIQUE,
    customer_id BIGINT NOT NULL,
    status VARCHAR(20) DEFAULT 'PENDING',
    total_amount DECIMAL(10, 2) NOT NULL,
    receiver_name VARCHAR(100),
    receiver_phone VARCHAR(20),
    shipping_address VARCHAR(255),
    remark VARCHAR(500),
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    cancel_time DATETIME,
    cancel_reason VARCHAR(255),
    cancel_role VARCHAR(20),
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);
```

#### 2. order_items（订单商品明细表）
```sql
CREATE TABLE order_items (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    order_id BIGINT NOT NULL,
    product_id BIGINT NOT NULL,
    quantity INT NOT NULL,
    unit_price DECIMAL(10, 2) NOT NULL,
    subtotal DECIMAL(10, 2) NOT NULL,
    FOREIGN KEY (order_id) REFERENCES orders(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);
```

#### 3. favorites（收藏表）
```sql
CREATE TABLE favorites (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    customer_id BIGINT NOT NULL,
    product_id BIGINT NOT NULL,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_customer_product (customer_id, product_id),
    FOREIGN KEY (customer_id) REFERENCES customers(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);
```

#### 4. shopping_cart（购物车表）
```sql
CREATE TABLE shopping_cart (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    customer_id BIGINT NOT NULL,
    product_id BIGINT NOT NULL,
    quantity INT NOT NULL DEFAULT 1,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_customer_product (customer_id, product_id),
    FOREIGN KEY (customer_id) REFERENCES customers(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);
```

## 🔧 核心业务逻辑

### 1. 订单创建流程
```java
public Order createOrderFromCart(Customer customer, List<Long> cartIds, ...) {
    1. 查询购物车商品
    2. 验证商品状态和库存
    3. 生成订单编号
    4. 创建订单和订单明细
    5. 扣减商品库存
    6. 删除购物车记录
    7. 返回订单对象
}
```

### 2. 订单状态流转规则
```
PENDING → confirmOrder() → CONFIRMED
CONFIRMED → prepareOrder() → PREPARING
PREPARING → shipOrder() → SHIPPING
SHIPPING → completeOrder() → COMPLETED
```

### 3. 订单取消规则
- **客户取消**：状态 < SHIPPING
- **商家取消**：状态 < COMPLETED
- 取消时恢复库存

### 4. 购物车转订单
支持选择多件购物车商品批量下单，下单成功后自动删除购物车记录。

### 5. 购物车转收藏
支持批量将购物车商品转为收藏，避免重复收藏，转换成功后删除购物车记录。

## ⚠️ 已知限制与注意事项

1. **订单状态流转不可逆**：订单状态只能按顺序流转，不能回退
2. **订单取消时机限制**：
   - 客户：只能在开始发货前取消
   - 商家：只能在交易完成前取消
3. **库存管理**：订单创建时扣减库存，取消时恢复库存
4. **购物车唯一性**：同一客户的同一商品只能有一条购物车记录（通过更新数量实现）
5. **收藏唯一性**：同一客户的同一商品只能收藏一次
