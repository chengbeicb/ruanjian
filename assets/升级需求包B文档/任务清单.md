## 🎯 核心功能特性

### 订单管理
- 订单编号自动生成（ORD + 时间戳 + 随机码）
- 订单状态严格流转（PENDING → CONFIRMED → PREPARING → SHIPPING → COMPLETED）
- 订单取消权限控制（客户/商家分别有不同取消时机）
- 订单取消原因记录
- 订单取消时自动恢复库存

### 收藏功能
- 客户-商品唯一约束（避免重复收藏）
- 收藏时间记录
- 批量收藏列表查询

### 购物车功能
- 购物车商品数量动态更新
- 购物车转收藏（批量操作）
- 从购物车创建订单（支持多商品）
- 下单后自动清空购物车对应商品

## 🚀 部署步骤

### 1. 更新数据库
```bash
# 在MySQL中执行
mysql -u root -p < scripts/init_database.sql
```

### 2. 编译后端项目
```bash
cd backend
mvn clean package
```

### 3. 启动后端服务
```bash
java -jar target/rjgcsj-backend-1.0.0.jar
```

参考 `API_TEST_GUIDE.md` 进行接口测试

## ⚠️ 注意事项
1. 所有接口均需要客户登录认证（除公开接口）
2. 订单状态流转有严格的顺序控制，不能跳过状态
3. 客户只能在开始发货前取消订单
4. 商家可以在交易完成前任意取消订单
5. 订单取消会自动恢复商品库存
6. 购物车和收藏都有客户-商品唯一约束
